# STUDENT-HABITS-AND-ACADEMIC-PERFORMANCE-ANALYSIS
Project Overview:
This project analyzes how different student habits and lifestyle factors affect academic performance. Using Power BI, interactive dashboards were created to explore relationships between study hours, sleep patterns, social media usage, exercise frequency, diet quality, and exam scores.

Dataset:
The dataset "Student Habits vs Academic Performance" was obtained from Kaggle.
It contains information about students such as study hours, attendance, sleep hours, social media usage, mental health rating, diet quality, and exam scores.

Tools Used:
Power BI
Power Query
Data Visualization

Dashboards:
The project includes the following dashboards:
Overview Dashboard
Study Behavior Analysis
Lifestyle and Well-Being Analysis

Key Insights:
Students who study more hours generally achieve higher exam scores.
Good attendance is associated with better academic performance.
Healthy lifestyle habits such as proper sleep and exercise positively influence student performance.
Excessive social media usage may negatively affect exam results.

Conclusion:
This project demonstrates how data visualization can help understand the relationship between student habits and academic performance. The Power BI dashboards provide clear insights that can help students and educators better understand factors affecting academic success.
